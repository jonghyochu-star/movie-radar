개인정보·이용 안내

적용 버전: 1.0 · 2026년 9월 18일

어떤 앱인가요?

Movie Radar는 YouTube API Services에서 받은 공개 영상 정보를 보고, 이용자가 직접 소재를 저장하고 제작 상태를 관리하는 개인용 도구입니다. YouTube 또는 Google의 공식 서비스가 아닙니다. 작품명·감동 여부·저작권 허락·Shorts 여부를 자동으로 보증하지 않습니다.

어떤 정보를 어디에 저장하나요?

GitHub Pages에는 공개 영상 ID, 원본 제목, 채널 정보, 조회수·구독자 수, 게시일, 길이, 썸네일 URL, 수집 시각이 배포됩니다. 누구나 이 사이트의 공개 수집 결과를 열어볼 수 있습니다. 비밀 API 키는 GitHub Actions Secrets에만 보관하며 사이트 파일에는 포함하지 않습니다.

앱 내부 좋아요·별로, 제작 후보·완료 상태, 사용자 작성 제목과 메모는 현재 브라우저의 localStorage에 저장합니다. 서버로 전송하거나 YouTube 계정에 반영하지 않습니다. 사이트 관리자에게 별도 이용 분석이나 개인 평가를 보내는 코드가 없습니다. 같은 기기·브라우저 프로필을 사용하는 다른 사람이 기록을 볼 수 있으므로 공용 PC에서 주의하세요.

저장한 소재의 API 정보 임시 사본은 수집일 기준 29일 이내에만 사용하며, 앱 실행 때 만료 사본을 삭제합니다. 이후에도 직접 저장한 영상 링크·평가·메모는 유지됩니다. 앱을 열지 않는 동안 브라우저 저장 공간 자체를 원격 삭제할 수는 없습니다. 정기 수집을 중단한 사이트는 오래된 공개 배포 데이터도 별도 폐기해야 합니다.

외부 서비스와 접속 정보

웹사이트를 여는 과정에서 GitHub에 일반 접속 정보가 전달될 수 있습니다. 실제 썸네일 로딩과 원본 YouTube 링크 클릭은 Google·YouTube에 요청을 보냅니다. 해당 서비스는 자신의 정책에 따라 쿠키·기기·접속 정보를 처리할 수 있습니다. 이 앱은 영상·오디오 파일을 저장하지 않고 재생을 YouTube에 맡깁니다.

백업과 삭제

‘내 기록 백업’은 사용자 작성 기록과 영상 ID를 JSON 파일로 내보냅니다. API에서 받은 조회수·채널명·썸네일 사본은 백업에 넣지 않습니다. ‘백업 복원’은 기존 기록과 합치되 동일 소재는 더 최근 사용자 기록을 우선합니다. ‘이 앱의 내 기록 삭제’는 현재 사이트의 앱 기록을 지우고 다른 앱의 localStorage를 지우지 않습니다. 내려받은 백업 파일은 사용자가 직접 보관·삭제해야 합니다.

이용 조건

본 앱을 이용하는 경우 YouTube 이용약관에 동의해야 합니다. Google 개인정보처리방침과 GitHub 개인정보처리방침도 확인하세요. 소재를 발견했다는 사실이 원작 이용 허락을 뜻하지 않습니다. 원작·출처·권리와 맥락은 제작자가 별도로 확인해야 합니다.

문의와 운영 범위

이 버전은 저장소 소유자 본인의 개인용 실행을 위한 것입니다. 다른 이용자에게 서비스를 제공하려면 운영자 연락처·보관 주기·동의 및 삭제 절차를 실제 운영 방식에 맞게 보완하고 플랫폼 이용 조건을 다시 확인하세요.

원작 확인 기록

원작 제작국 분류는 사용자가 직접 확인해 입력한 기록입니다. YouTube 영상의 제목, 사용 언어, 채널 국가만으로 영화 제작국을 자동 판정하지 않습니다. 한국 영화 제외는 해당 영상 ID에 적용되며 다른 편집본까지 자동으로 제외하지 않습니다. 원작 분류도 기존 좋아요·메모와 함께 이 브라우저에만 저장하고 사용자 백업에 포함합니다.
