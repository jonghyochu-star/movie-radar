개인정보·이용 안내

적용 버전: 1.8.1 · 2026년 9월 23일

어떤 앱인가요?

Movie Radar는 YouTube API Services에서 받은 공개 영상 정보를 보고, 이용자가 직접 소재를 저장하고 제작 상태를 관리하는 개인용 도구입니다. YouTube 또는 Google의 공식 서비스가 아닙니다. 작품명·감동 여부·저작권 허락·Shorts 여부를 자동으로 보증하지 않습니다.

어떤 정보를 어디에 저장하나요?

GitHub Pages에는 공개 영상 ID, 원본 제목, 채널 정보, 조회수·구독자 수, 게시일, 길이, 썸네일 URL, 수집 시각이 배포됩니다. 비밀 API 키는 GitHub Actions Secrets에만 보관하며 사이트 파일에는 포함하지 않습니다.

앱 내부 좋아요·별로, 제작 후보·완료 상태, 사용자 작성 제목과 메모, 원작/형식 확인 기록은 현재 브라우저의 localStorage에 저장합니다. 서버로 전송하거나 YouTube 계정에 반영하지 않습니다.

백업 폴더와 로컬 권한

지원되는 데스크톱 브라우저에서 ‘백업 폴더 지정/변경’을 누르면 사용자가 직접 기준 폴더를 선택합니다. 앱은 그 위치 안에 Movie Radar/Backups 폴더를 만들고, 이후 ‘내 기록 백업’ 시 JSON 파일을 그 폴더에 씁니다.

선택한 폴더의 접근 핸들은 브라우저의 IndexedDB에 로컬로 저장될 수 있습니다. 폴더 내용이나 핸들은 Movie Radar 서버, GitHub, YouTube로 전송하지 않습니다. 브라우저가 권한을 다시 요구하거나 권한이 만료된 경우 사용자가 다시 허용해야 할 수 있습니다. 폴더 직접 저장이 지원되지 않거나 권한이 없으면 기존 다운로드 폴더 저장 방식으로 자동 전환합니다.

백업과 삭제

‘내 기록 백업’은 사용자 작성 기록과 영상 ID를 JSON 파일로 내보냅니다. API에서 받은 조회수·채널명·썸네일 사본은 백업에 넣지 않습니다. ‘백업 복원’은 기존 기록과 합치되 동일 소재는 더 최근 사용자 기록을 우선합니다. ‘이 앱의 내 기록 삭제’는 현재 사이트의 앱 기록을 지우지만 사용자가 직접 저장한 백업 파일은 삭제하지 않습니다.

외부 서비스와 접속 정보

웹사이트를 여는 과정에서 GitHub에 일반 접속 정보가 전달될 수 있습니다. 실제 썸네일 로딩과 원본 YouTube 링크 클릭은 Google·YouTube에 요청을 보냅니다. 해당 서비스는 자신의 정책에 따라 쿠키·기기·접속 정보를 처리할 수 있습니다. 이 앱은 영상·오디오 파일을 저장하지 않고 재생을 YouTube에 맡깁니다.

이용 조건

본 앱을 이용하는 경우 YouTube 이용약관에 동의해야 합니다. Google 개인정보처리방침과 GitHub 개인정보처리방침도 확인하세요. 소재를 발견했다는 사실이 원작 이용 허락을 뜻하지 않습니다. 원작·출처·권리와 맥락은 제작자가 별도로 확인해야 합니다.

원작·필터 기록

원작 제작국 분류와 영화·드라마 여부, 쇼츠/일반 영상 구분은 사용자가 직접 확인해 남길 수 있는 별도 기록입니다. 한국 영화 제외·일반 영상 제외·영화·드라마 아님은 좋아요/별로와 서로 다른 상태로 보존합니다.
