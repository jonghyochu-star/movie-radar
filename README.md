# Movie Radar · 1.8

1.8은 1.7에서 확인된 **영화·드라마 수집 정확도**를 유지하면서, 브라우저에 쌓인 좋아요/별로 기록을 실제 후보 순서에 반영합니다.

## 핵심

- 영화/TV 주제 게이트와 비영화 제외 로직은 1.7 그대로 유지합니다.
- 좋아요뿐 아니라 **별로 기록도 취향 신호**로 사용합니다.
- 한국 영화 제외 / 일반 영상 제외 / 영화·드라마 아님은 취향 신호로 사용하지 않습니다.
- 후보를 감동 점수로 채점하지 않습니다.
- 후보를 다음 네 그룹으로 설명합니다.
  - `♥ 취향 가까움`: 좋아요가 더 많았던 채널 또는 이야기 유형과 겹침
  - `↗ 인접한 새 결`: 좋아요가 더 많았던 탐색 경로와 겹치지만 같은 이야기만 반복하지 않음
  - `✦ 새로운 결`: 좋아요/별로 어느 쪽과도 직접 겹치지 않는 탐색
  - `↓ 낮은 적중 경로`: 별로가 더 많았던 단서와 겹침
- `내 취향 우선` 정렬에서는 **50% 취향 가까움 / 30% 인접한 새 결 / 20% 새로운 탐색**을 목표로 번갈아 보여줍니다. 해당 그룹 후보가 부족하면 다른 그룹으로 채웁니다.
- 낮은 적중 경로도 삭제하지 않고 뒤에 남겨 새로운 취향 변화 가능성을 막지 않습니다.

## 기존 기록

현재 브라우저의 기존 좋아요·별로 기록을 그대로 읽습니다. 다시 평가할 필요가 없습니다.

장기 백업에는 사용자 행동이 보존되지만 API 메타데이터는 장기 저장하지 않으므로, 오래된 기록의 채널/탐색 맥락은 현재 목록 또는 유효한 임시 캐시가 있을 때 가장 잘 활용됩니다.

## 다음 수집

Actions 입력 방식은 1.7과 동일합니다. 1.8의 좋아요/별로 학습은 우선 **브라우저 표시 순서**에 적용합니다. 다음 API 수집은 기존처럼 좋아요 씨앗 ID를 선택적으로 사용합니다. 별로 데이터를 서버 수집기에 자동 전송하지는 않습니다.
