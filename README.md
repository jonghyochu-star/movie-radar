# Movie Radar · 1.8.1

1.8.1은 1.8의 추천/취향 로직을 그대로 유지하면서 **백업 파일을 찾기 쉬운 폴더에 저장**할 수 있게 하는 작은 사용성 패치입니다.

## 새 기능: 백업 폴더 지정

- 하단의 `백업 폴더 지정/변경`을 한 번 누릅니다.
- Windows에서는 **문서(Documents)** 같은 기준 폴더를 선택하는 것을 권장합니다.
- 앱이 선택한 위치 안에 `Movie Radar/Backups` 폴더를 자동으로 만듭니다.
- 이후 `내 기록 백업`을 누르면 그 폴더에 다음처럼 저장합니다.
  - `movie-radar-backup-2026-09-23_1228.json`
- 선택한 폴더 핸들은 브라우저의 IndexedDB에 로컬로만 보관합니다. 서버나 GitHub로 전송하지 않습니다.
- 브라우저가 권한을 다시 요구하면 백업 버튼을 누를 때 한 번 허용하면 됩니다.
- 폴더 저장을 지원하지 않는 브라우저이거나 권한이 없으면 기존처럼 **다운로드 폴더 저장으로 자동 대체**합니다.

## 보존되는 데이터

기존과 같습니다. 좋아요, 별로, 한국 영화 제외, 영화·드라마 아님, 쇼츠/일반 영상 확인, 제작 후보/완료, 사용자 메모와 제목을 백업합니다. API 조회수·채널명·썸네일의 장기 사본은 백업하지 않습니다.

## 적용

`site`, `tests`, `README.md`를 기존 저장소에 덮어쓰면 됩니다. YouTube 수집기와 GitHub Actions는 바뀌지 않으므로 이 패치 자체로 API 호출은 늘지 않습니다.
