# Movie Radar · 1.9.2

Movie Radar의 목표는 **시청자 반응이 강한 영화·드라마 후보를 넓게 찾고, 내가 쓸 만한 소재만 빠르게 남기는 것**입니다.

## 1.9.2에서 바뀐 핵심

화면을 기능 중심이 아니라 **작업 흐름 중심**으로 단순화했습니다.

기본 화면에서 바로 판단할 것은 네 가지뿐입니다. **결 맞음**을 누르면 같은 카드가 사라지지 않고 바로 `많이 본 소재 / 전개 약함 / 선택 완료 → 다음` 세부 판단이 열립니다.

- **♥ 결 맞음**: 내가 찾는 정서·관계·이야기 결에 맞음
- **결 아님**: 취향 자체가 맞지 않음
- **★ 제작 후보**: 실제로 만들고 싶은 소재. 누르면 결 맞음도 함께 저장
- **영화·드라마 아님**: 검색 실패로 구조적 제외

결 맞음 영상은 필요할 때만 두 가지 세부 표시를 추가합니다.

- **많이 본 소재**: 결은 맞지만 신선도가 떨어짐
- **전개 약함**: 결은 맞지만 이야기 힘이 부족함

기존 1.8.2 기록도 자동 보존합니다. 예전에 별로 → 많이 본 소재로 저장한 것은 결 맞음 + 많이 본 소재, 별로 → 전개 약함은 결 맞음 + 전개 약함으로 자동 변환됩니다.

## 화면 구성

주 메뉴는 새 후보 / 결 맞음 / 제작 후보 / 제작 완료 / 기록 다섯 개입니다.

구독자 수, 발견 경로, 상세 언어·길이 조건, 백업, 수집 설정 등은 **수집 · 필터 · 백업 설정** 안으로 접었습니다. 카드에서도 구독자 수와 조회/구독 배율을 기본 화면에서 제거하고 조회수, 게시일, 시청자 반응, 네 가지 판단 버튼만 먼저 보이게 했습니다.

## 시청자 반응 레이어

구독자 수와 평생 평균 조회속도는 기본 선별 기준으로 쓰지 않습니다.

- 12시간 이내 20만+
- 24시간 이내 50만+
- 48시간 이내 100만+
- 3일 이내 200만+
- 5일 이내 500만+
- 7일 이내 500만+
- 누적 500만+ 검증
- 누적 1000만+ 초대형 검증
- 반복 수집 후 실제 Δ12h / Δ24h / Δ7d 추적

오래된 500만 영상은 전체 업로드 기간으로 나눠 약한 영상처럼 만들지 않습니다.

## 앞으로의 흐름

```
YouTube API
→ 영화/TV 후보
→ 시청자 반응 검증
→ 사용자 결/품질 평가
→ 향후 SRT/텍스트 AI 1차
→ 필요한 후보만 영상 AI
→ 제작 후보
```

AI가 연결되기 전에도 현재 평가는 그대로 쌓이며, 이후 취향·신선도·이야기 힘·제작 의사 신호를 서로 섞지 않고 활용할 수 있게 설계합니다.
