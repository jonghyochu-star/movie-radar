# Movie Radar · Starter 1.2

기존 `movie-radar` 저장소용 업데이트입니다. `.github/workflows/movie-radar.yml`, GitHub Secret `YOUTUBE_API_KEY`, 기존 `site/data/videos.json`은 유지합니다. 실제 수집 후 사용하려면 새 main 브랜치에서 mode=live를 실행하세요.

## 기본 화면 조건

| 조건 | 기본값 | 변경 방법 |
|---|---|---|
| 공개 구독자 수 | 1만 이하 | 5천 / 1만 / 5만 / 제한 없음 |
| 조회수 | 10만 이상 | 기존 최소 조회수 선택 |
| 영상 길이 | 0~180초 | 1분 이하 / 30~90초 / 1~3분 / 2~3분 / 직접 입력 |
| 영상 종류 | 영화·드라마 단서 있음 | 영화 단서만 / 전체(미확인·비영화 의심 포함) |
| 언어 | 영어·일본어·스페인어·포르투갈어·프랑스어·독일어·이탈리아어·중국어 | 언어 체크박스 또는 모든 언어 |
| 언어 미확인 | 기본 숨김 | ‘언어 미확인 포함’ 선택 |
| 배열 | 언어·채널 골고루 | 끄면 선택한 정렬순 그대로 |

필터는 소재 탐색과 원작 확인 필요 탭에만 적용됩니다. 보관함·제작 후보·완료 기록에는 탐색 필터를 적용하지 않습니다. 직접 한국 영화 또는 비영화로 제외한 항목은 평가 기록에서 되돌릴 수 있습니다.

- 상한은 현재 API의 공개 구독자 수 기준입니다. 과거 게시 시점의 구독자 수가 아닙니다. 구독자 수를 알 수 없으면 상한 필터에서 통과시키지 않습니다. 공개 구독자 수는 내림 처리된 수치이므로 실제 구독자가 경계값을 조금 넘을 가능성이 있습니다.
- 길이는 원작 장편 길이가 아니라 수집한 YouTube 편집본 길이입니다. 수집기는 3분 이하 영상만 보관합니다. 3분을 넘는 범위는 이 버전에서 지원하지 않습니다.
- 화면의 조건 변경은 이미 수집된 목록에 적용되며 YouTube API를 호출하지 않습니다. 목록 새로고침도 배포된 JSON을 다시 읽는 동작입니다. 새로운 검색은 Actions의 새 main/live 실행입니다.
- 모든 언어를 선택해도 검색어 자체가 추가되지는 않습니다. 기본 수집의 검색어 풀은 아래 8개 언어입니다. 다른 언어의 결과가 교차 검색되면 사용자 언어 설정으로 표시할 수 있습니다. 다른 언어를 적극 발굴하려면 config.json의 queries를 바꾸어야 합니다.
- 조건을 만족하는 소재가 0개면 0개로 표시합니다. 조회수나 구독자 조건을 몰래 완화하거나 결과를 만들어 내지 않습니다. 화면의 단계별 남은 개수로 제한 원인을 확인하세요.

## 수집 변경

검색은 매번 영어 1개 + 나머지 7개 언어 중 3개를 순환합니다. 힌디어·아랍어 전용 검색어는 기본 풀에서 제거했습니다. 이는 원작 제작국을 제외하는 필터가 아니며, 인도 등 한국 외 국가의 영화를 제작국만으로 제외하지 않습니다.

각 검색어에 대해 최근 30일 조회수순 검색(영화 topic)과 전체 기간 관련도순 검색(topic 제한 없음)을 실행합니다. 후자는 검색 분류가 부족한 영화 편집·드라마 장면도 찾기 위한 경로입니다. 검색 요청은 기본 구성에서 재시도 제외 최대 8회입니다. 영상·채널 정보 요청은 별도로 발생합니다. 검색 언어는 결과 언어를 보장하지 않으며, regionCode로 제작국을 판정하지 않습니다.

## 영화·언어 필터의 한계

`scripts/screen_rules.py`는 외부 AI 호출 없이 제목·설명·태그·API 분류의 단서를 검사하는 **규칙 기반 1차 선별기**입니다. 실제 영상·음성·자막을 분석하지 않습니다.

- `film`: 영화 장면 표현, 명시적 작품 표기 등 단서.
- `series`: TV/시리즈/드라마 장면 표현 등 단서.
- `unknown`: 근거 부족. 단일 `#movie` 태그만으로 확인 처리하지 않습니다.
- `non_screen`: 게임 플레이·브이로그·뮤직비디오 등 비영화 의심 단서.
- 문맥 오탐과 좋은 영화의 누락이 가능합니다. ‘전체’에서 미확인 자료를 검토하거나 사용자 확인으로 종류 분류를 바꿀 수 있습니다.
- 영화 단서는 원작 영화명이나 제작국을 검증한 결과가 아닙니다. 한국 영화 여부는 기존의 원작 확인 절차를 유지합니다.
- 언어는 제목 문자, 업로더의 제목/음성 언어 설정, 일부 단어 규칙을 참조합니다. 문자권만 알 수 있으면 ‘아랍 문자권’, ‘인도계 문자권’, ‘키릴 문자권’처럼 표시하며 특정 국가·언어로 단정하지 않습니다. 원작 제작국은 추정하지 않습니다.
- 언어·채널 균형 표시는 존재하는 자료를 번갈아 배열합니다. 전역 조회수 내림차순과 다릅니다. 특정 언어만 충분한 경우 뒤쪽은 그 언어가 많을 수 있습니다. 영상은 임의로 복제하거나 누락시키지 않습니다.

## 사용자 기록

1.0/1.1의 localStorage 키와 schema=1을 유지합니다. 새 `media` 필드(unknown/screen/not_screen)는 기존 기록에 자동 보완하며 좋아요·제작 상태·메모·원작 판단을 바꾸지 않습니다. ‘영화·드라마 아님’은 취향의 별로와 별개입니다. 표시 필터는 별도 브라우저 설정으로 저장합니다.

사용자 기록 백업에는 평가·메모·제작 상태·직접 확인한 원작/종류가 포함되며 API 메타데이터 캐시는 제외합니다. 필터 설정은 기록 백업과 별개로 이 브라우저에 저장됩니다. 다른 브라우저에서 동일한 기본값이 적용되므로 필요하면 필터를 다시 선택하세요.

## 설치

1. 기존 앱에서 ‘내 기록 백업’ 실행. 백업 JSON은 GitHub에 올리지 않습니다.
2. 이 업데이트 `upload` 폴더의 내용물 5개(scripts/site/tests/config.json/README.md)를 기존 저장소 최상위에 업로드합니다. 폴더 자체를 감싸서 올리지 않습니다.
3. Commit changes로 main에 저장합니다. 기존 `.github` 및 `site/data/videos.json`은 삭제하지 않습니다.
4. Actions → Movie Radar → Run workflow → Branch main, mode live → 실행. 이전 실행의 Re-run은 쓰지 않습니다.
5. build/deploy 성공 후 앱에서 Ctrl+Shift+R. 상단 1.2, 필터 영역, ‘YouTube 연결’을 확인합니다. 새 수집 데이터가 아닌 경우 앱이 안내합니다.

API 키를 재발급하거나 Secret에 다시 넣을 필요는 없습니다. 기존 자동 실행 설정은 변경하지 않습니다.

## 테스트

```sh
python -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/test_core.cjs
```

46 Python 테스트 + 49 JavaScript 테스트, 총 95개가 로컬에서 통과했습니다. 모의 데이터·모의 localStorage를 사용하는 Chromium 화면 시나리오 16개도 통과했습니다. 환경의 브라우저 네트워크 탐색 제한으로 네이티브 새로고침/다운로드 대신 직렬화·재수화와 백업 페이로드를 테스트했습니다. 실제 YouTube API 호출, 실제 검색 정확도, 사용자 GitHub 배포는 이번 패키지에서 수행하지 않았습니다. 기존 workflow는 Python 테스트를 실행하며 JavaScript 테스트는 제공된 명령으로 별도 실행 가능합니다.
