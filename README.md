# Movie Radar · 1.4.1

개인용 영화·드라마 쇼츠 소재 탐색 앱의 **수집 제어 업데이트**입니다. 기존 좋아요·메모·제작 후보는 브라우저에 그대로 남습니다.

## 1.4.1에서 추가로 바뀐 것

- 좋아요를 누르면 카드 테두리와 버튼이 **♥ 좋아요 저장됨**으로 유지되어 저장 여부를 바로 확인할 수 있습니다.
- 1~3차 재탐색 사이의 정확한 영상 ID 중복은 GitHub Actions 캐시로 한 번 더 막고, 제목이 거의 같은 재업로드도 고신뢰 메타데이터 지문으로 억제합니다.
- `english_focus`는 이번 실행에서 실제 선택된 언어만 수집 결과에 남겨, 참고 채널에서 스페인어 등이 과도하게 새어 들어오는 현상을 줄입니다.
- 주요 기능에 마우스를 올리면 짧은 설명이 나타납니다.

## 1.4에서 바뀐 것

- **표시 언어와 다음 수집 언어를 분리**했습니다.
- 수집 언어 프리셋: `english_focus`(영어 중심·4개 검색 슬롯 중 3개 영어), `english_only`(영어만), `balanced`(다국어 균형), `custom`(직접 비중).
- 4개 검색 슬롯 기준 `english_focus`는 기본적으로 **영어 3개 + 다른 언어 1개**를 사용합니다.
- `retry_round=1/2/3`으로 소재가 없을 때 검색 경로를 바꿉니다. **구독자·조회수·길이 같은 화면의 하드 조건을 자동 완화하지 않습니다.**
- 이전 배포의 영상 ID를 공개 Pages 데이터에서 읽어 다음 수집에서 제외합니다. 최대 5,000개까지 이어서 보관합니다. 읽기에 실패하면 경고 후 정상 수집합니다.
- 앱의 **오늘 수확 없음**은 해당 수집 묶음에 대한 피드백으로 로컬 저장·백업됩니다. 자동 취향 학습은 1.5 이후 단계입니다.
- 앱의 **다른 소재 더 찾기**는 다음 재탐색 값을 복사하고 GitHub Actions 화면을 엽니다. 공개 Pages에서 비밀 토큰 없이 Actions를 직접 실행하지 않습니다.

## 수동 수집

GitHub → **Actions → Movie Radar → Run workflow**에서 입력합니다.

- `mode`: `live`
- `collect_preset`
  - `english_focus`: 영어 중심. 기본 추천
  - `english_only`: 영어로 확인된 후보만 출력
  - `balanced`: 지원 언어를 순환
  - `custom`: `custom_weights` 사용
- `custom_weights`: 예 `en:70,ja:10,es:10,fr:10`
- `retry_round`
  - `1`: 기본 탐색
  - `2`: 다른 감동·새 소재 비중 강화
  - `3`: 새로운 소재 탐색을 더 넓힘

한 번의 live 실행은 기존과 동일하게 검색 요청을 최대 8회 사용합니다(재시도·영상/채널 정보 조회는 별도).

## 자동 수집

워크플로에는 **매일 07:23 KST** 예약이 있습니다. 자동 실행은 기본적으로 꺼져 있습니다.

Repository → Settings → Secrets and variables → Actions → **Variables**에서:

- `AUTO_COLLECT` = `true`
- `AUTO_COLLECT_PRESET` = `english_focus` 권장
- `AUTO_COLLECT_WEIGHTS` = `custom`을 사용할 때만 입력

예약 실행은 항상 1차 탐색으로 시작합니다. 그날 후보가 마음에 들지 않으면 앱에서 `오늘 수확 없음` → `다른 소재 더 찾기` 순서로 2차, 필요하면 3차 수동 재탐색을 사용합니다.

## 중요한 구분

- **표시 언어**: 이미 배포된 목록을 브라우저에서 필터링합니다.
- **수집 언어**: 다음 GitHub Actions live 실행에서 검색 언어를 결정합니다.
- 영어로 수집했다고 원작 국가가 영어권이라고 판단하지 않습니다.
- 한국 영화 제외는 여전히 사용자가 원작을 확인한 뒤 기록합니다.
- 제목의 `#shorts`, 짧은 길이만으로 Shorts를 확정하지 않습니다.
- 참고 영상은 취향의 상한선이 아니며, 새로운 감동결 탐색 경로를 항상 남깁니다.

## 파일

- `.github/workflows/movie-radar.yml`: 수동 입력과 자동 예약 수집
- `scripts/discovery.py`: 수집 언어 비중·1/2/3차 탐색 경로
- `scripts/collect.py`: YouTube 수집, 이전 배포 ID 제외
- `site/`: 화면, 수집 계획, 수확 없음 피드백
- `tests/`: 오프라인 테스트
