# Movie Radar · 1.8.2

1.8.2는 기존 `별로` 기록을 전부 취향 반대 신호로 학습하면 안 된다는 실제 사용 피드백을 반영한 데이터 품질 패치입니다.

## 별로 이유 분리

앞으로 `별로`를 누르면 네 가지 이유 중 하나를 고릅니다.

- **내 결 아님**: 감정·관계·이야기 방향 자체가 취향과 다름 → 취향 반대 신호로 사용
- **많이 본 소재**: 결은 맞지만 이미 익숙함 → 신선도 문제로 보존, 취향 반대 학습에는 사용하지 않음
- **전개 약함**: 결은 맞을 수 있으나 재미·전환·완결성이 약함 → 이야기 완성도 문제로 보존, 취향 반대 학습에는 사용하지 않음
- **기타**: 이유는 보존하지만 취향 반대 학습에는 사용하지 않음

기존 1.8.1 이전의 `별로` 기록에는 이유가 없으므로 **이유 미분류**로 유지합니다. 기존 별로를 임의로 `내 결 아님`으로 바꾸지 않습니다.

## 좋아요와 제외 기록

- 좋아요는 계속 강한 긍정 취향 신호입니다.
- 한국 영화 제외, 일반 영상 제외, 영화·드라마 아님은 구조적 제외 신호로 유지하며 취향 학습과 분리합니다.
- 기존 백업 파일은 그대로 복원 가능하며 새 `dislikeReason` 필드가 없으면 null로 안전하게 마이그레이션합니다.

## Gemini 실험과의 관계

Gemini 교차검증에서는 기존 별로 24개를 단순 음성 정답으로 취급하지 않습니다. 좋아요는 긍정 예시로 사용하고, 앞으로 이유가 명확히 쌓인 별로만 목적에 맞게 분리해 검증합니다.
