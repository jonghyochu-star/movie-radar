# Movie Radar · 1.6.2

이번 패치는 **후보를 더 많이 버리는 대신, 볼 순서를 더 똑똑하게 정리**합니다.

## 핵심

- 카드에 `추천 우선 / 확인 필요 / 비영화 의심` 근거 배지를 표시합니다. 점수는 만들지 않습니다.
- `추천 우선` 정렬을 추가했습니다. 영화·드라마 근거가 비교적 분명한 후보를 먼저 보여줍니다.
- 현재 브라우저의 **좋아요 기록을 표시 순서에만 반영**할 수 있습니다.
  - 좋아요한 영상과 같은 채널
  - 좋아요한 영상과 겹치는 탐색 경로(familiar/expand/work/open)
  가 있으면 `♥ 좋아요 참고` 배지가 붙고 같은 근거 수준 안에서 앞쪽에 배치됩니다.
- 좋아요 취향 반영은 후보를 삭제하거나 숨기지 않으며 YouTube API 수집도 바꾸지 않습니다.
- 한국 영화 제외, 일반 영상 제외, 영화·드라마 아님 기록은 기존대로 별도 상태로 보존됩니다.
- 좋아요 기록의 장기 보존은 사용자 행동 자체만 백업합니다. API 메타데이터는 장기 백업하지 않으므로, 오래된 좋아요의 채널/경로 맥락은 현재 수집 또는 유효한 임시 캐시가 있을 때만 로컬 정렬에 사용됩니다.

## 왜 이렇게 했나

1.6.1에서 후보 고갈 문제를 완화한 뒤, 다음 병목은 **후보 품질 순서**였습니다. 1.6.2는 임의의 감동 점수 대신 확인 가능한 근거를 층으로 나누고, 좋아요는 약한 개인화 신호로만 사용합니다. 새로운 소재 탐색은 계속 남습니다.

## 적용

`site`, `tests`, `README.md`만 기존 저장소에 덮어쓰면 됩니다. 수집기와 Actions 설정은 바꾸지 않으므로 추가 API 호출은 없습니다.
