# Movie Radar · Starter 1.0

개인 영화 쇼츠 소재 수집·보관·제작 후보 관리 앱입니다. 기존 Shorts Radar와 별도 저장소에 배포하세요.

## 구성

- `site/`: GitHub Pages에 배포할 HTML/CSS/JavaScript와 공개 데이터.
- `scripts/collect.py`: Python 표준 라이브러리로만 작성한 YouTube 공개 API 수집기.
- `config.json`: 기본 검색어, 길이, 수집 개수와 선택적인 영상·채널 ID.
- `tests/`: 네트워크 호출 없는 수집기·상태 처리 단위 테스트.
- `.github/workflows/movie-radar.yml`: 설치 패키지의 `movie-radar-workflow.txt` 내용을 이 경로로 등록.

## 최초 실행

1. 새 public 저장소 최상위에 이 내용물을 업로드합니다.
2. Settings → Pages → Source를 **GitHub Actions**로 설정합니다.
3. 동봉된 워크플로를 `.github/workflows/movie-radar.yml`로 등록합니다.
4. Actions → Movie Radar → Run workflow → `demo`로 실행합니다.
5. `YOUTUBE_API_KEY`를 Repository Secret에 등록하고 `live`로 실행합니다.
6. 정상 확인 후 Repository Variable `AUTO_COLLECT=true`로 매일 한국시간 07:23 예약을 켭니다.

워크플로는 수동 실행과 선택적 예약 실행만 사용합니다. 파일 수정만으로 재배포하지 않습니다.
예약은 실행 서비스 사정에 따라 지연될 수 있습니다. API 오류는 배포를 중단하며 이전 사이트를 유지합니다.
API 키·비밀번호·개인 백업을 소스 파일이나 이 저장소에 올리지 마세요.

## 기능과 구분

좋아요와 제작 후보는 별도 상태입니다. 후보 해제는 좋아요를 지우지 않고, 제작 완료는 부정 평가가 아닙니다.
나중에 넘기기는 해당 탐색 세션에서만 처리합니다. 평가 기록, 메모, 직접 이름은 브라우저에 보관합니다.
카드 한 장 / 목록 20개를 전환할 수 있습니다. `목록 새로고침`은 이미 배포된 데이터 재조회이며 YouTube 검색 실행 버튼이 아닙니다.

검색은 기본 검색어 12개 중 4개를 실행마다 순환하여 최근 30일과 전체 기간을 각각 탐색합니다.
수집 코드는 기본 최대 8번의 `search.list` 요청과 상세 데이터 요청을 합니다. 재시도 때 요청 수가 늘 수 있습니다.
10~180초의 공개 영상 후보를 모으며 영어 검색 우선 설정은 미국 제작자·영화·감동결·Shorts 판정을 보장하지 않습니다.
조회/구독 배율은 단순 나눗셈이고, 성공 확률이나 채널 점수가 아닙니다. 숨김·0 구독자 수는 계산하지 않습니다.

## 보관과 개인정보

Public 저장소와 Pages 데이터는 공개됩니다. 개인 평가·메모는 서버로 보내지 않고 현재 브라우저 localStorage에 저장합니다.
다른 PC와 자동 동기화되지 않으며 시크릿 모드나 사이트 데이터 삭제에 주의하세요.
내 기록 백업은 사용자 데이터와 영상 ID만 포함하며 API 통계·제목·썸네일 사본은 포함하지 않습니다.
현재 수집 목록 밖 자료는 직접 쓴 이름·메모로 찾아볼 수 있습니다. API 캐시는 29일이 지나면 앱 실행 시 제거됩니다.
영상을 다운로드하지 않고 YouTube 링크로 원본을 엽니다. 원작 권리·작품명·맥락은 직접 확인해야 합니다.
장기 운영·타인 대상 서비스 전에는 개인정보 안내와 API 이용 조건을 실제 운영 방식에 맞게 검토하세요.

## 이 버전에 없는 것

AI 내용 분석, 자동 취향 학습, 틱톡·인스타 자동 수집, 상시 서버, 클라우드 개인 보관함, 자동 편집.
평가 기록은 학습을 위한 기반이지만 이 버전에서 개인화 모델을 훈련하거나 실행하지 않습니다.
OpenAI API 호출은 없습니다.

## 로컬 개발자 테스트 (일반 설치 사용자는 실행할 필요 없음)

```sh
python -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/test_core.cjs
python scripts/collect.py --mode demo
```

실제 API 키와 해당 계정 GitHub 배포는 사용자 설정 후 검증해야 합니다.
