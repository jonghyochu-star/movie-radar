# Movie Radar · 1.9

1.9의 목표는 **AI가 보기 전에, YouTube 시청자에게 이미 강하게 선택된 후보를 먼저 남기는 것**입니다.

## 시청자 반응 레이어

구독자 수와 `조회수 ÷ 구독자`는 더 이상 기본 선별 기준이 아닙니다. 또한 쇼츠가 초기에 크게 성장한 뒤 몇 달 후 피드가 멈출 수 있다는 점 때문에 **현재 조회수를 영상 전체 나이로 나눈 평생 평균 조회속도는 사용하지 않습니다.**

대신 세 종류의 근거를 따로 봅니다.

1. **게시 후 구간별 누적 조회수**
   - 12시간 이내: 20만+
   - 24시간 이내: 50만+
   - 48시간 이내: 100만+
   - 3일 이내: 200만+
   - 5일 이내: 300만+
   - 7일 이내: 500만+
2. **누적 시장 검증**
   - 500만+ : 검증된 대형 후보
   - 1000만+ : 초대형 검증 후보
3. **실제 반복 관찰 증가량**
   - 약 12시간 Δ 20만+
   - 약 24시간 Δ 50만+
   - 약 7일 Δ 200만+

위 숫자는 1.9의 **초기 검증값**이며 실제 결과를 2~3회 본 뒤 조정합니다.

## 실제 조회수 스냅샷

GitHub Actions의 비공개 캐시에 최근 후보 최대 150개의 조회수 스냅샷을 저장합니다. 이후 수집에서 같은 영상을 다시 확인해 실제 Δ12h / Δ24h / Δ7d를 계산합니다.

- 과거 조회수를 역산하지 않습니다.
- 처음 발견하기 전의 성장 속도는 모른다고 처리합니다.
- 오래된 500만 영상은 1년으로 나눠 약한 영상처럼 만들지 않고 **누적 500만 검증**으로 별도 표시합니다.
- 최근 약 100일 동안 후보를 추적합니다.

## 화면

기본 `시청자 반응` 필터는 **강한 반응·검증 영상만**입니다.

카드에는 다음과 같은 근거 배지가 표시됩니다.

- 🔥 지금 급상승
- 🚀 게시 구간 강반응
- ★ 500만+ 검증
- ★★ 1000만+ 검증
- 관찰 중

`전체 후보 · 진단용`으로 바꾸면 반응 기준을 통과하지 못한 후보도 볼 수 있습니다.

## AI와의 연결

향후 Gemini에는 모든 검색 결과를 보내지 않고, **시청자 반응 레이어를 통과한 후보를 먼저 전달**하는 구조를 목표로 합니다.

```
YouTube API
→ 영화/TV 후보
→ 시청자 반응 검증
→ SRT/텍스트 AI 1차
→ 필요한 후보만 영상 AI
→ 최종 소재
```

1.8.2에서 추가한 별로 이유 분리와 백업 폴더 기능은 그대로 유지됩니다.
